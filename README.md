

# 📂 Data Structures

This module covers foundational data structures and algorithms essential for efficient programming and problem-solving. It includes practical implementations and use-cases of searches, sorting techniques, recursion, and linear data structures like stacks, queues, and linked lists.

Key topics include:

* **Search algorithms** like linear search and binary search for locating elements in arrays or sorted data.
* **Sorting algorithms** such as bubble sort, selection sort, insertion sort, merge sort, and quicksort to organize data efficiently.
* **Hashing** for constant-time data access using hash tables and maps, with a focus on collision handling and performance trade-offs.
* **Stacks and Queues** for LIFO and FIFO operations, useful in parsing, expression evaluation, and scheduling problems.
* **Recursion** as a fundamental technique for breaking down problems into smaller subproblems, including base cases and recursive calls.
* **Linked Lists** for dynamic memory management and efficient insertions/deletions, including singly, doubly, and circular linked lists.
